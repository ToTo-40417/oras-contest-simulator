# GitHub公開候補の再監査

対象は `oras-contest-github-ready.zip` のファイル一覧です。作業用フォルダ全体や、既存のGUI配布ZIPは対象に含みません。

## ROMと公開ソース

- 保存していたPokéAPI、Ribbon Helper、公開NPC表の入力から、作業フォルダ外で5種類のデータを再生成して比較しました。ポケモンとフォームのデータは一致しました。比較時に前回削除済みの技説明文とNPCニックネームを除くと、差分は「でんじは」のコンボ2組、効果21の妨害値、NPC4人の技枠順だけでした。これらは計算に使うルールや値であり、ゲームの実行命令列や文章は含みません。
- ROMダンプ、ROM解析スクリプト、ダンプから抽出したバイナリ、逆アセンブル出力、ゲーム画面、画像・音声素材を配布一覧から除外しました。カートリッジの処理を調べて再実装したPythonの規則と、公開資料を基にした名称・数値データは残しています。
- 配布するJPEGはローカルGUIを実行して撮影した画面です。ゲームの画面やブラウザのタブ、端末の情報は写っていません。
- Ribbon Helper、PokéAPI、RFC 8682のライセンス通知を同梱します。ゲーム名・技名などの固有名詞および第三者データの利用について、権利者の承認を取得したことを示す監査ではありません。ツール独自部分の公開条件は [LICENSE](../LICENSE) に記載し、第三者資料の出典と条件は [NOTICE](../NOTICE.md) にまとめています。

## ファイルと動作

- 配布一覧の全テキストを対象に、メールアドレス、端末の絶対パス、代表的な秘密鍵やアクセストークンの形式を走査しました。該当なし。Git履歴、キャッシュ、元資料は同梱していません。
- 実際のブラウザでトドゼルガを選択し、マスター5種目の結果が表示された画面を撮影しました。ZIPを空のフォルダへ展開し、回帰テスト31件とREADMEのCLI例を実行しました。
