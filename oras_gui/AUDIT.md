# 公開前監査

独立したエージェントがCLIのソース、同梱データ、出典とライセンス、公開候補に紛れ込む端末情報、通常の入力とカスタム重みの動作を確認した。

| 発見事項 | 対応 |
| --- | --- |
| 効果データの36件にゲーム内の英語文言と一致する説明があった | 計算に使わない説明文を削除した |
| NPCのニックネーム69件が計算に不要だった | ニックネームを削除した |
| 既存Pythonキャッシュ3件に端末のアカウント識別子を含むパスがあった | キャッシュを配布ZIPから除外し、Gitでも無視するよう設定した |
| カスタム重みのNPC名の誤記や、NPCが使えない技が無視された | データに照らして入力時にエラーを返すよう変更した |
| 巨大な有限の重みを指定すると抽選が失敗した | 必要な場合は相対比を保ったまま正規化するよう変更した |

配布ZIPにはソース、実行用のデータ、ライセンス、利用ガイドを収録。ROM、元資料、Git履歴、端末キャッシュは含まない。ZIPの全ファイルを対象に、メールアドレスと一般的なホームディレクトリの絶対パスのパターンを再検査した。

ゲーム名・ポケモン名などの固有名詞、および計算に必要な技・NPCのデータを使用する。データの出典と利用条件は計算エンジンのREADMEと同梱ライセンスを参照。監査は具体的な混入・動作確認を対象とし、ゲーム名や第三者のデータに関する配布許諾の取得は行っていない。
