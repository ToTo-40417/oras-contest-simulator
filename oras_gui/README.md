# ORAS コンテスト戦略シミュレーター GUI

ZIPを展開してから、お使いのOSの起動ファイルをダブルクリックしてください。Python 3.10以降が必要です。

- macOSは `Start ORAS.command`
- Windowsは `Start ORAS.bat`

起動ファイルを使えない場合は、展開先のフォルダで次を実行してください。

```sh
python3 -B -m oras_gui.server
```

既定のブラウザが開きます。開かない場合は、起動ウィンドウに表示されたURLを開いてください。終了するときは起動ウィンドウで Ctrl+C を押します。計算は手元のPCで行います。

「すべての種目」「すべてのランク」を選ぶと、20部門の順位率をまとめて表示します。空欄にしたターンは、行動可能な場合でも技を出さないモデルとして計算します。結果のJSONには試行誤差の区間とモデルの仮定も含まれます。
